# Nature-style contact-map plots

Dataset-specific plotting code, metric tables, manifests, logs, and outputs are separated:

- `1_HiCImputedData/`: HiCImputeData main grid, 7k supplement grid, and per-method single-panel plots.
- `2_FLAMINGOData/`: FLAMINGOData 7x9 grid. No active per-method single-panel plot is maintained.
- `gr_style.py`: shared publication style and output helper.

Do not add dataset-specific CSV files or figures to this directory.
