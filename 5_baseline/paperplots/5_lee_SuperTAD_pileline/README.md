# Lee PDGFRA SuperTAD Pipeline

## Overview

This pipeline evaluates imputation methods on the Lee et al. human cortex scHi-C dataset, focusing on the PDGFRA locus (`chr4:55095461-55164412`, hg19, 10 kb resolution).

For each cell type, all cells are used to construct a target pseudo-bulk map. The pipeline then performs 100 repeated trials, randomly samples 30 cells in each trial, aggregates their imputed matrices into a pseudo-bulk map, and calculates its PCC against the target. SuperTAD is also used to identify TAD boundaries.

Multiple imputation methods can be evaluated independently. Outputs for each method are stored in a method-specific subdirectory.

## Data Formats

### `input_lee/per_cell_npz/` (shared imputation input)

Each file stores the 49 x 49 contact matrix of one cell as a SciPy sparse CSR NPZ.

- Filename: `{CellType}_cell_{idx:04d}.npz`
- Cell types: Astro (449), Endo (202), ODC (1,244), and OPC (203)
- Matrix: 49 x 49, symmetric, upper triangle with `k=1` and no diagonal
- Region: `chr4:54,890,000-55,380,000` (10 kb, 49 bins)
- PDGFRA subregion: bins 20-28 (8 x 8)

### `imputed/{method}/` (generated by an imputation method)

Run the imputation method on every cell under `input_lee/per_cell_npz/` and save the outputs under `imputed/{method}/`.

Requirements:

- Filename: `{CellType}_cell_{idx:04d}.npz`, in one-to-one correspondence with `input_lee`
- Format: SciPy sparse CSR NPZ
- Matrix: 49 x 49 and symmetric (`M + M.T`)
- Values: floating-point values in count space
- Diagonal: optional; it is set to zero during PCC calculation

```python
from scipy.sparse import load_npz, save_npz, csr_matrix
import numpy as np

raw = load_npz("input_lee/per_cell_npz/Astro_cell_0000.npz").toarray()
imputed = your_method(raw)
imputed = imputed + imputed.T
save_npz("imputed/YourMethod/Astro_cell_0000.npz", csr_matrix(imputed))
```

### `target/` (prepared and shared)

The target pseudo-bulk maps were aggregated from per-cell `.cool` files.

## Workflow

### Prerequisites

- Python 3.8 or later with NumPy, SciPy, pandas, Matplotlib, and seaborn
- `bin/SuperTAD` is included for arm64 macOS; recompile it for Linux
- Prepared `input_lee/` and `target/` directories

### Step 1: Run Imputation

Save imputed results under `imputed/{method}/`:

```bash
mkdir -p imputed/YourMethod
# Run the imputation method and write outputs to imputed/YourMethod/.
# Filename: {CellType}_cell_{idx:04d}.npz
```

Validate the file counts:

```bash
for ct in Astro Endo ODC OPC; do
    echo "$ct: $(ls imputed/YourMethod/${ct}_cell_*.npz 2>/dev/null | wc -l) files"
done
```

### Steps 2-4: Evaluation and Plotting

```bash
python run_trials.py --method YourMethod      # 100 sampling trials and PCC
python run_supertad.py --method YourMethod    # SuperTAD boundary calling
python plot_results.py --method YourMethod    # Generate figures
```

Outputs are written to `trials/YourMethod/`, `supertad/YourMethod/`, and `figures/YourMethod/`.

### Comparing Multiple Methods

Repeat the workflow for each method; outputs remain separated by method:

```bash
# Method 1
python run_trials.py --method scHiC-Diff
python run_supertad.py --method scHiC-Diff
python plot_results.py --method scHiC-Diff

# Method 2
python run_trials.py --method HiCImpute
python run_supertad.py --method HiCImpute
python plot_results.py --method HiCImpute
```

Figures are stored under `figures/scHiC-Diff/` and `figures/HiCImpute/`, respectively.

## Key Parameters (`config.py`)

| Parameter | Value | Description |
|---|---:|---|
| `N_TRIALS` | 100 | Number of repeated trials |
| `N_SAMPLE` | 30 | Number of cells sampled per trial |
| `BASE_SEED` | 42 | Base random seed (`seed=42+trial_id`) |
| `N_BINS` | 49 | Matrix dimension |
| `RESOLUTION` | 10000 | 10 kb resolution |
| `PDGFRA_SUB_BINS` | (20, 28) | PDGFRA 8 x 8 subregion |
| `SUPERTAD_HEIGHT` | 3 | SuperTAD `multi` hierarchy level |

## Notes

1. Filenames under `imputed/{method}/` must correspond one-to-one with those under `input_lee/per_cell_npz/`.
2. Imputed results must remain in count space, not log-transformed space.
3. Matrices must be symmetric.
4. The included SuperTAD binary targets arm64 macOS. Recompile it and replace `bin/SuperTAD` on Linux.
5. `--method` is required and identifies the imputation method.
